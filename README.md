# 📊 Google Play Store Data Analysis

## 📌 Project Overview
This project analyzes the Google Play Store dataset to uncover insights about app trends, ratings, pricing, and user sentiment.

## 🎯 Objectives
- Data Cleaning & Preprocessing
- Category-wise Analysis
- App Metrics Analysis (Rating, Installs, Price, Size)
- Sentiment Analysis on User Reviews
- Interactive Data Visualization

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib & Seaborn
- Plotly
- TextBlob (NLP)

## 📊 Key Insights
- Most apps belong to the **Family** category
- Free apps dominate the platform
- Higher installs generally correlate with better ratings
- User sentiment is mostly positive

## 📁 Dataset
- apps.csv
- user_reviews.csv

## 🚀 How to Run
1. Open the notebook in Google Colab
2. Upload dataset files
3. Run all cells
